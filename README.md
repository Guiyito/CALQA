> **Sentoni, G. & Delauro, M. (2025)**  
> *Uncovering Learning Patterns in Neural Computing Course: a Sequential Analytics Approach Applied to AI Education*  
> 55 JAIIO — Simposio Argentino de Educación en Informática (SAEI), 2025.  
> Universidad Nacional de La Matanza, Buenos Aires, Argentina.

---

## Overview

This repository contains the full reproducible pipeline for the CALQA study — a sequential learning analytics framework applied to a fully online university course on neural computing.

The framework combines three components:

1. **Semantic FSM v6** — transforms raw Moodle event logs into pedagogically meaningful observable states: `NAV`, `REC`, `PRACT`, `QUIZ`, `EVAL`, `FB`, `OTHER`
2. **Trajectory clustering** — K-Means (K=4) over per-student FSM proportions
3. **Hidden Markov Model (HMM K=4)** — infers latent cognitive modes Z0–Z3 via Baum-Welch + Viterbi

### Central finding

Latent state **Z2 (Regulated Active Learner)** — characterized by active computational practice (PRACT) combined with formative quizzes (QUIZ) in the mid-to-late learning trajectory — is the **only mode significantly associated with academic performance** (Spearman ρ = +0.599, p = 0.030).

| Latent state | Dominant FSM | Cognitive mode | ρ vs grade |
|---|---|---|---|
| Z0 | REC | Reader / resource explorer | −0.26 (ns) |
| Z1 | NAV | Superficial navigator | −0.05 (ns) |
| **Z2** | **PRACT + QUIZ** | **Regulated active learner** | **+0.60 *** |
| Z3 | OTHER | Passive / diffuse | −0.13 (ns) |

## FSM v6 — Semantic mapping

The FSM maps each raw Moodle event to one of 7 observable states using semantic rules anchored in the pedagogical design of the course:

| State | Description | Key rule |
|---|---|---|
| `NAV` | Course navigation | `course: viewed`, `section: viewed` |
| `REC` | Resource consumption | Videos, PDFs, development pages |
| `PRACT` | Active computational practice | Context includes `"practica"`, `"python"`, architecture names |
| `QUIZ` | Formative quiz interaction | Quiz attempt started/viewed/reviewed |
| `EVAL` | Summative evaluation | Quiz component + `"submitted the attempt"` |
| `FB` | Feedback | `"updated the grade"`, grade viewed |
| `OTHER` | Residual events | Everything else |

**PRACT** captures interactions with the CPIAE console (Pyodide-based interactive Python environment), which are the primary vehicle for active learning in the course.

## Data privacy

All student data has been anonymized: real names and institutional emails have been replaced with `student1`–`student13` / `studentN@uni.edu.ar`. Internal Moodle IDs in event descriptions are masked as `'XXXXX'`. The equivalence table (real ↔ anonymous) is not included in this repository.
